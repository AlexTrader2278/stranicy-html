# GEMINI.md

Инструкции для Gemini CLI и Antigravity — в файле `AGENTS.md`.

Коротко:

1. Прочитать `AGENTS.md`.
2. Написать черновик `.md` по правилам из раздела 4.
3. Собрать: `node scripts/am.mjs render draft.md -o out/page.html --no-open`.
4. Проверить вывод: `✓` и `STE 0 warnings`.
5. Если Node.js нет, отдать только черновик `.md` и сказать человеку: «соберите командой из README».

HTML руками не писать. Числа без источника не ставить.
