# stranicy-html — ответ одной HTML-страницей

Репозиторий делает из сложного ответа одну читаемую HTML-страницу.
Агент пишет короткий черновик в Markdown. Сборщик `scripts/am.mjs` делает вёрстку,
тёмную тему, диаграммы и сетку панелей. Руками HTML не пишется.

Сборщик — один файл, без зависимостей. Нужен только Node.js 20 или новее.

## Быстрый старт

```bash
git clone https://github.com/AlexTrader2278/stranicy-html
cd stranicy-html
node --version                                   # нужно 20 или новее
node scripts/am.mjs render examples/01-prigon-avto.md -o out/prigon.html --no-open
```

Сборщик печатает `✓ out/prigon.html`. Откройте файл в браузере: страница
самодостаточна, интернет не нужен.

## Как это работает

1. Агент читает `AGENTS.md` и пишет черновик `draft.md` по правилам формата.
2. Сборщик собирает страницу: `node scripts/am.mjs render draft.md -o out/page.html`.
3. Проверка: строка `✓` в выводе и `STE 0 warnings`. Ошибки `✗` печатаются с примером исправления.

```bash
node scripts/am.mjs render draft.md -o out/page.html --no-open   # собрать
node scripts/am.mjs patch out/page.html --panel "Название" new.md # заменить одну панель
node scripts/am.mjs lint draft.md                                 # только проверка текста
node scripts/am.mjs help format                                   # справка по формату
```

## Что в репозитории

| Путь | Что это |
|---|---|
| `AGENTS.md` | Правила для агента: когда делать страницу, как писать черновик |
| `GEMINI.md` | Короткая ссылка на `AGENTS.md` для Gemini CLI и Antigravity |
| `docs/format.md` | Полный список компонентов и синтаксиса черновика |
| `scripts/am.mjs` | Сборщик (Node 20+, без зависимостей) |
| `examples/01-prigon-avto.md` | Пример черновика: процесс сделки и участники |
| `examples/02-sezonnost.md` | Пример черновика: шаблон отчёта с графиком |
| `prompts/rynok-avto.md` | Готовое задание для исследования рынка авто |
| `out/` | Куда складывать готовые страницы (в git не попадает) |

## Два способа работы

**С терминалом.** Агент с доступом к файлам (Gemini CLI, Antigravity, Claude Code,
Codex, Hermes) клонирует репозиторий, пишет черновик и запускает сборщик сам.

**Без терминала.** Чат-модель отдаёт только текст. Тогда она пишет черновик `.md`,
а сборку запускает человек или другой агент с Node.js. Один и тот же черновик
даёт одну и ту же страницу.

## Проверка качества

- Одна панель отвечает на один вопрос. Панелей 3–8.
- Первая панель или строка `Lead` даёт главный вывод.
- Каждая цифра имеет источник и дату. Данные без источника не ставятся.
- Демонстрационные числа помечаются словом «демо» в описании.
