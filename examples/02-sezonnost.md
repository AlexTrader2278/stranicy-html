Lead: Шаблон страницы о рынке. Числа здесь демонстрационные. Их заменяют данными Автостата, АЕБ и банков.

## Как заполнять

1. Собрать продажи по месяцам за пять лет из одного источника.
2. Считать индекс сезонности: месяц делить на средний месяц года.
3. Отметить месяцы, где индекс ниже 90.
4. Добавить события: повышение утильсбора, ставка по кредиту, курс.

## Что проверить в каждом месяце

| Месяц | Вопрос к данным | Статус |
|---|---|---|
| Январь | Провал после декабрьских скидок или рост цен | warn |
| Март–апрель | Старт сезона, влияние повышения пошлин | ok |
| Июль–август | Пик спроса, сроки доставки | ok |
| Ноябрь | Клиенты ждут новогодних акций | warn |
| Декабрь | Скидки дилеров, закрытие плана | ok |

## Источники для сверки

```kv
Продажи новых: АЕБ, помесячные пресс-релизы
Продажи с пробегом: Автостат
Импорт: ФТС и ЕЭК
Ставки по кредиту: обзоры банков
Цены: Авто.ру и Авито, аналитика
```

```callout info Правило сверки
Одну цифру берут из одного источника. Второй источник нужен для проверки, а не для замены.
```

```callout err Не делать так
Не рисовать график по оценке без источника. Читатель примет оценку за факт.
```
