# Формат черновика

Черновик — расширенный Markdown. Файл состоит из шапки, строки `Lead` и панелей.
Вёрстку, цвета и схемы делает сборщик. Проверка синтаксиса: `node scripts/am.mjs help format`
и `node scripts/am.mjs help <компонент>`.

## Шапка

```markdown
---
template: sheet
theme: auto
title: Заголовок страницы
subtitle: Одна строка под заголовком
cols: 3
style: 80
mode: auto
source: Автостат, октябрь 2026
lang: ru
---
```

| Поле | Значение |
|---|---|
| `title` | Заголовок. Вместо него можно начать текст строкой `# Заголовок` |
| `subtitle` | Подзаголовок, одна строка |
| `template` | `sheet` — сетка панелей на один экран (по умолчанию); `doc` — чтение в одну колонку с оглавлением |
| `theme` | `auto` (по умолчанию), `blueprint`, `shadcn`, `paper` |
| `cols` | Число колонок сетки, по умолчанию 3. Широкие таблицы и схемы подстраиваются сами |
| `style` | Строгость проверки текста: `off`, `80` (по умолчанию, только предупреждения), `strict` (страница не собирается) |
| `mode` | `auto` по системе, `light`, `dark` |
| `lang` | Язык страницы, например `ru` |
| Любое другое поле | Показывается в шапке как справка, например `source: …` |

## Панели

```markdown
## A Название панели
Текст обычным Markdown.
```

- `## ` начинает панель. Идентификатор `A`, `B`, `C` ставится автоматически.
- `{span=2}` после названия просит широкую панель. Нужно редко: сборщик сам подбирает ширину.
- `{meta="заметка"}` добавляет пометку в правом верхнем углу панели.

## Компоненты

Компонент — блок кода, где языком указано его имя.

### Схема процесса и связей

````markdown
```flow LR
(Клиент) -> [Менеджер]: заявка
[Менеджер] -> {Лот одобрен?}: расчёт
{Лот одобрен?} -> [(Аукцион)]: да
[Менеджер] --> [Архив]: отказ
group Офис: Менеджер, Архив
```
````

- Направление: `TB` (по умолчанию), `LR`, `BT`, `RL`.
- `->` сплошная линия, `-->` пунктир, `A -> B -> C` цепочка, `A -> B & C` разветвление.
- Форма узла: `(Начало)` скруглённый, `{Вопрос?}` ромб, `[(База)]` цилиндр, `[Текст: с двоеточием]` прямоугольник.
- `*Узел` выделяет узел. `group Имя: A, B` рисует общую рамку.
- Изменения плана: строка начинается с `+` (добавлено), `-` (удалено), `~` (изменено).

### Обмен сообщениями

````markdown
```sequence num
participants: Клиент, Менеджер, Склад
Клиент -> Менеджер: заявка
Менеджер --> Клиент: расчёт и срок
note Клиент, Менеджер: договор подписан
== Оплата ==
Клиент -> Склад: платёж
```
````

### Иерархия

````markdown
```tree
Компания | отдел продаж
  Менеджеры
    Пригон
  Логистика | порт и автовоз
  *Бухгалтерия
```
````

Отступ задаёт уровень. `|` добавляет серую заметку. `list` превращает схему в список.

### Этапы во времени

````markdown
```timeline
Неделя 1 | Заявка | бюджет и марка
*Недели 4–6 | Фрахт | судно до порта
```
````

`время | заголовок | пояснение`. До шести пунктов идут в строку, больше — столбцом. Направление задаётся `h` или `v`. `*` выделяет пункт.

### Сущности и поля

````markdown
```er LR
Клиент
  id PK
  телефон string UK
Договор
  id PK
  клиент_id FK -> Клиент
Клиент 1--* Договор: заключает
```
````

### Значение против предела

````markdown
```limits
Срок доставки | 70 / 60 | дней | просрочка
Предоплата | max 30 | процентов
```
````

Превышение предела подсвечивается красным.

### Числа

````markdown
```chart bar unit=шт
        | план | факт
*Октябрь | 5    | 1
Сентябрь | 5    | 0
```
````

- Виды: `bar`, `bar horizontal`, `line`, `pie`.
- Первая строка без чисел называет серии. Она нужна, если чисел в строке два и больше.
- `*` выделяет строку. `unit=` подписывает ось.
- `line` рисует точку на каждом значении. Одно число на строку — самый простой вариант.

### Разбор фразы

````markdown
```annot
# Пример | справа пояснение
Клиент вносит [предоплату]{не всю сумму}, остаток — [при выдаче]{!проверить договор}.
```
````

`[фрагмент]{пояснение}`. `!` перед текстом делает заметку красной.

### Титульный блок

````markdown
```kv cols=2
*Кому: менеджер по продажам
Срок: октябрь 2026
Вопрос: почему один договор
```
````

`*` растягивает строку на всю ширину.

### Плашка вывода

````markdown
```callout warn Главный риск
Ставка считается на дату оформления.
```
````

Виды: `info` (по умолчанию), `ok`, `warn`, `err`.

### Выбор читателя

````markdown
```ask
Что проверяем первым?
* Базу клиентов | она холодная
- Лиды с Авито
```
````

### Таблица со статусами

В ячейке пишется `ok`, `no` или `warn`. Сборщик рисует значок.

```markdown
| Шаг | Риск | Статус |
|---|---|---|
| Фрахт | Срок сдвинулся | warn |
| Осмотр | Машина принята | ok |
```

### Код, файл, картинка

````markdown
```ts src=scripts/render.ts lines=18-30 hl=22
```

```diff file=scripts/render.ts
```

![Экран отчёта](out/screen.png)
````

- `src=` вставляет строки настоящего файла. Текст блока при этом пустой.
- Картинка стоит одна на своей строке, путь абсолютный или от папки черновика. Размер до 5 МБ.
- Картинки для того, что не рисуется схемой. Придуманные картинки не ставятся.

## Lint и ошибки

```bash
node scripts/am.mjs lint draft.md
```

- `✗ L12 [chart] …` — ошибка. Страница не собрана, в выводе есть пример правильной записи.
- `STE` — предупреждения о длине фраз и канцелярите. Сборке не мешают.
- Правка панели готовой страницы: `node scripts/am.mjs patch out/page.html --panel "Название" panel.md`.
  Черновик берётся из скрытого `#am-source` внутри страницы, поэтому исходник не нужен.
